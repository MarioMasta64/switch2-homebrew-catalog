# Switch 2 Homebrew Catalog

A community homebrew catalog for Nintendo Switch 2.

## Catalog URL

Paste this direct URL into your homebrew store's catalog settings:

```text
https://raw.githubusercontent.com/dadadush/switch2-homebrew-catalog/main/catalog/catalog.tsv
```

The store downloads `artwork.bin` from the same folder. Refresh the catalog in the store to receive published changes.

## Files

- `catalog/catalog.tsv` — application details, download links and checksums.
- `catalog/artwork.bin` — application thumbnails.

Application files are downloaded from their developers' release pages.
