# Switch 2 Homebrew Catalog

A community homebrew catalog for Nintendo Switch 2, designed for [IZ2S Cheese](https://github.com/byizmysh/iz2s-cheese).

it is recommended to use [DadaDush's Version](https://github.com/dadadush/switch2-homebrew-catalog) as i will be updating this fork frequently and things may break however my version will often feature more items as i find them at random before they are added to dadadush's version

all updates here are manually done by hand, the automated script i use only produces the attached info (type, description, hash, filesize) i pick the nro for releases manually because i dont trust a scraper for that

## Catalog URLs

In IZ2S Cheese, open **Settings → Catalog URL** and paste the address for your version.

**IZ2S Cheese 0.8.7 and later only**

```text
https://raw.githubusercontent.com/MarioMasta64/switch2-homebrew-catalog/main/catalog/catalog-new.tsv
```

IZ2S Cheese downloads `artwork.bin` from the same folder for the catalog. Press **Y → Refresh** in the catalog to get the latest list and thumbnails.

## Files

- `catalog/catalog-new.tsv` — the IZSTORE3 catalog. It can group a single app's IZA and NRO builds under one entry.
- `catalog/artwork.bin` — application thumbnails.
